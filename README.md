# Power-BI-Spotify-Dashboard-project
My project name is Spotify Music Analytics Dashboard.

In this project, I analyzed Spotify music data to understand song performance, artist popularity, and streaming trends.

I created an interactive dashboard using Power BI.

First, I cleaned and prepared the data. Then, I created different visualizations and KPIs, such as Total Streams, Danceability, Energy, and Valence.

I also created charts to analyze top tracks by streams, popular artists, streams by released year, and track characteristics.

I used filters like Artist Name, Released Year, Key, and Mode to make the dashboard interactive.
